주일 소그룹 출석을 휴대폰·컴퓨터에서 간편하게 기록하고,
우리 그룹의 출석을 한눈에 살펴봅니다.

출석부란?

종이 대신, 어디서나 클릭 한 번으로

매주 소그룹 모임 후, 리더가 직접 출석을 체크하고 나눔·심방 내용을 남깁니다. 기록은 자동으로 저장되어, 우리 그룹의 출석 흐름을 언제든 다시 볼 수 있습니다.

📱 앱 설치 없이 교회 웹사이트에서 카카오 로그인만 하면 바로 사용할 수 있어요.

✅

출석 체크

주차별로 우리 그룹원의 출석을 체크박스로 표시합니다.

📝

특이사항·기타 의견

그룹원별 심방·기도제목과 그룹 전체의 의견을 기록합니다.

📊

출석률 보기

주차별·구성원별 출석률을 그래프로 한눈에 확인합니다.
