## 남은 일

1. **`send-notification` 함수 배포.** 지금도 함수 주소만 알면 외부에서 임의 내용으로 전 교인에게 푸시를 보낼 수 있다.
   - 코드는 고쳐 두었다(Flutter 저장소). 본문의 메시지 id로 DB에서 다시 읽고, 만든 지 5분이 넘은 메시지는 보내지 않는다.
   - Firebase 비밀키 파일이 같이 올라가야 하므로 CLI로 배포한다:
     `supabase login` 후 `supabase functions deploy send-notification --project-ref nfivyduwknskpfhuyzeg --no-verify-jwt`
   - 지금 배포된 v32(2025-02-21)는 저장소 소스보다 오래됐다. 배포하면 그사이 커밋(알림 중복 방지 태그 등)도 함께 나간다.
   - 더 근본적으로는 webhook이 비밀 헤더를 보내고 함수가 그것을 확인하게 바꾼다.
2. **로그인 사용자의 컬럼 제한 (2단계).** 앱이 `custom_users`를 `select('*')`로 읽어서 *보이는 행*의 전화·이메일은 아직 내려간다.
   앱이 필요한 컬럼만 읽도록 업데이트·배포한 뒤 `authenticated`의 컬럼 권한을 회수한다.
3. **실기기 확인.** 앱 로그인·프로필 저장·요람, 웹 출석부를 실제로 써 본다.
