# 차량번호 수집 — 개인정보처리방침 반영 기록

주차 관리 기능(`/parking/my`, `/parking`)에 따른 방침 개정 내용입니다.
문구는 `src/routes/privacy/+page.svelte` 에 **반영 완료**했고, 아래는 근거와 남은 절차입니다.
법률 검토를 대신하지 않습니다.

## 왜 필요했나

차량번호는 그 자체로 특정 개인을 알아볼 수 있어 **개인정보보호법상 개인정보**입니다.
이 방침의 `1.1 수집항목` 은 수집 항목을 열거하는 방식이라, 목록에 없는 항목을 수집하면
방침과 실제가 어긋납니다.

## 반영한 문구 (4곳)

| 섹션 | 추가 내용 |
|---|---|
| 1.1 수집항목 | **선택항목(주차 관리)**: 차량번호, 차량 메모 — 등록하지 않아도 다른 서비스 이용에 제한 없음 |
| 2. 이용목적 | 주차 질서 유지 및 주차 수요 파악 (이중주차 시 차주 확인·연락 용도로만) |
| 5. 보유기간 | 차량번호: 회원 탈퇴 시 또는 이용자가 직접 삭제할 때까지 |
| 7. 이용자 권리 | 등록한 차량번호는 '내 차량' 메뉴에서 직접 조회·삭제 가능 |

- **선택항목**으로 둔 근거: 등록하지 않아도 다른 기능에 제한이 없고, 구현도 본인이 원할 때만
  등록·삭제하도록 되어 있습니다.
- **보유기간**이 실제와 일치하는 근거: 프로필 삭제 시 `ON DELETE CASCADE` 로 함께 지워지고,
  `/parking/my` 에서 언제든 본인이 삭제할 수 있습니다.

## 접근 권한 (구현 기준)

방침의 "제3자 제공하지 않음" 과 어긋나지 않도록 DB 단에서 제한했습니다.

| 대상 | 열람 범위 |
|---|---|
| 본인 | 본인이 등록한 차량만 |
| 주차 담당자(`parking_managers`) | 전체 차량 + 차주 이름·연락처 |
| 관리자(level ≥ 100) | 전체 |
| 그 외 교인 | **조회 불가** (RLS 로 차단, 시뮬레이션 검증 완료) |

- 담당자 지정·해제는 관리자만 가능하며 변경 이력은 `audit_logs` 에 남습니다.
- 차량번호 자체는 감사 로그에 복제하지 않습니다(열람 범위가 넓어지는 것을 막기 위해).

## 등록 화면 안내 문구

> 차량번호는 전체 공개되지 않습니다. 본인과 주차 담당자(안내위원)·관리자만 볼 수 있으며,
> 이중주차 등으로 연락이 필요할 때 차주를 확인하는 용도로만 사용합니다. 언제든 직접 삭제할 수 있습니다.
